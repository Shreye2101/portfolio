# 🌐 Shreyash Srivastava - Animated 3D Portfolio Website

A modern, highly interactive personal portfolio website built with **Next.js**, **Three.js**, **Framer Motion**, and **GSAP**, showcasing my skills, projects, and social presence — all brought to life with engaging 3D visuals and smooth animations.

## 🚀 Live Demo

> Coming soon on [https://shreyash-portfolio.vercel.app](https://shreyash-portfolio.vercel.app)

## ✨ Features

- 🌀 **3D Animated Landing Page**  
  Using Three.js for dynamic visuals (e.g., floating particles or a 3D avatar)

- 💫 **Smooth Motion & Transitions**  
  Framer Motion and GSAP used to animate sections, elements, and page routing

- 📸 **Animated Hero Image**  
  My photograph elegantly animated into view on page load

- 🧾 **Resume Download Button**  
  Stylish, animated button to download my resume (PDF)

- 📱 **Responsive Design**  
  Looks great on all screen sizes — mobile, tablet, desktop

- 🌐 **Social Media Integration**  
  Interactive icons linking to:
  - [LinkedIn](https://linkedin.com/in/shreye2101)
  - [GitHub](https://github.com/Shreye2101)
  - [Instagram](https://instagram.com/shreye___)

- 💼 **Projects Showcase**  
  Beautifully animated cards displaying my featured projects

- 🎯 **Parallax & Scroll Animations** (Optional)  
  Using GSAP ScrollTrigger for scroll-based effects

## 🛠️ Tech Stack

- **Frontend:** Next.js (React)
- **3D Graphics:** Three.js
- **Animations:** Framer Motion, GSAP
- **Icons:** React Icons
- **Styling:** CSS Modules / TailwindCSS (depending on setup)
- **Deployment:** Vercel
